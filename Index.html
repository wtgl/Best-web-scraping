Scraping

Modern web verilerini kolayca ve hizlica ayiklayin

Genel Bakis

Scraping, modern web projeleri icin gelistirilmis yuksek performansli bir veri ayiklama ve yonetim kutuphanesidir. Gelismis secim metodlari, esnek mimarisi ve hizli veri isleme yetenekleri sayesinde web uzerindeki verilere erismeyi ve bunlari yapilandirmayi son derece kolaylastirir.

Kurulum

Projeyi sisteminize kurmak ve calistirmak icin asagidaki adimlari takip edebilirsiniz.

1. Depoyu bilgisayariniza klonlayin:

git clone https://github.com/wtgl/scraping.git

2. Proje dizinine giris yapin:

cd scraping

3. Gerekli bagimliliklari ve kutuphaneyi pip kullanarak yukleyin:

pip install .
