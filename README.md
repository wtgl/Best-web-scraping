Scraping, modern web projeleri icin gelistirilmis yuksek performansli bir veri ayiklama ve yonetim kutuphanesidir. Gelismis secim metodlari, esnek mimarisi ve hizli veri isleme yetenekleri sayesinde web uzerindeki verilere erismeyi ve bunlari yapilandirmayi son derece kolaylastirir.
